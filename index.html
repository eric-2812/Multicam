Run every camera from one screen and the keyboard.

Focus, shutter, ISO, white balance and zoom for each camera, where its hardware offers them. Switch the program live with cuts and transitions, slate every file at once, and set any key to any action.

  • C and Shift + C step the shutter, I the ISO, Z the zoom
  • Tally on every phone: red on air, green on preview
  • Lost cameras reconnect by themselves

Your recordings stay on your computer.

Cortiva has no account, no cloud and no analytics. Files are written straight to the folder you choose, and settings are saved on this computer only. The code is open under the GPL v3, so anyone can check it.

  • Free, with no watermark and no time limit
  • The Windows app updates itself between takes
  • Remembers your cameras, mics and settings
