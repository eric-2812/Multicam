How multicam recording works

  1. Start the recording with REC

    Every armed camera, every microphone and the live program start together, on the same frame and the same timecode.

  2. One recording file per camera and mic

    Each camera and each mic gets its own file in the take's folder, with an edit list of your cuts and a sheet of every setting.

  3. Edit the multicam clip

    Drop the folder into Premiere Pro, DaVinci Resolve or Final Cut Pro: the files line up by timecode with no hand syncing.

Camera control in the app, from the keyboard. Every setting the camera's hardware offers, on one screen.

  • C and Shift + C step the shutter, I the ISO, Z the zoom, and any key can be changed
  • Focus, white balance and exposure for each camera, where it has them
  • Cuts and transitions to the live program, with tally on every phone
  • A slate that flashes and beeps on every file at once
  • Cameras that drop out reconnect by themselves
